# 🏠 Apartment Virtual Tour (AVT)

An interactive 3D virtual tour of an apartment built with Unity and WebGL.

## 🎮 Controls

### **Camera Movement**
- **WASD Keys** - Move forward/backward/left/right
- **Left Mouse + Drag** - Pan camera (swipe to move)
- **Right Mouse + Drag** - Look around (FPS style)
- **Mouse Scroll Wheel** - Zoom in/out

### **View Modes**
- **Virtual Tour Button** - First-person exploration mode
- **Top View Button** - Bird's eye overview mode

## ✨ Features

- 🎯 **Smooth Camera Controls** - Intuitive navigation with mouse and keyboard
- 🔍 **Zoom Functionality** - Scroll wheel to zoom in/out (FOV 20-90°)
- 🏃 **Multiple Movement Options** - WASD keys or mouse drag
- 👁️ **Free Look** - Right-click to look around freely
- 🗺️ **Dual View Modes** - Switch between tour and overview
- 🎨 **Realistic 3D Model** - Detailed apartment with furniture
- 🌐 **WebGL Build** - Runs in any modern browser

- Use **right-click + drag** for the best looking experience
- **Scroll wheel** to zoom in on details
- Press **Virtual Tour** button to reset camera position
